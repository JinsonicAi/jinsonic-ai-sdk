# AIBox 智能算法平台宣传彩页

## 让 AI 算法真正跑进现场

AIBox 智能算法平台面向园区、工厂、社区、门店、交通、仓储和安防等边缘视觉场景，提供从视频接入、AI 推理、区域规则、事件判断、报警推送到录像留证的一体化能力。平台采用插件化算法架构，支持 AX650N / AX8850、RK35xx / RV1126B、AXCL 算力卡等多种硬件形态，可在边缘侧完成实时分析，降低云端带宽和后端计算压力。

它不是单一算法 Demo，而是一套可交付、可扩展、可运维的边缘 AI 软件系统。

---

## 核心卖点

### 1. 全链路边缘智能

平台在边缘端完成 RTSP 拉流、硬件解码、图像预处理、NPU 推理、OSD 叠加、报警截图、录像存储和网络推送，减少视频原始流上传，提升实时性和隐私安全性。

适合以下部署：

| 部署形态               | 适用场景               | 价值                       |
| :--------------------- | :--------------------- | :------------------------- |
| AX 一体机              | 独立边缘盒子、工业现场 | 本地闭环处理，部署简单     |
| RK 本地设备            | RK 主机、轻量边缘终端  | 本地 RKNN 推理，降低成本   |
| RK / x86 + AXCL 算力卡 | 多路视频、高并发场景   | 算力扩展灵活，支持多卡混用 |

### 2. 插件化算法生态

每个算法以 `.plugin` 形式独立交付，包含算法逻辑、UI 配置、模型资源和报警协议。系统运行时动态加载插件，便于升级、替换和按项目裁剪。

插件化带来的优势：

- 算法能力可按需安装，不影响主程序稳定性。
- 新算法可以快速接入现有视频流、区域绘制、报警推送和录像链路。
- 不同项目可组合不同插件，形成行业解决方案。
- 支持算法热更新和多版本交付，降低现场维护成本。

### 3. 多平台统一运行

平台抽象了统一的 Runtime Location，算法插件不需要关心底层是 AX 本地、RK 本地还是 AXCL 算力卡。任务创建时选择运行位置，系统自动匹配解码、预处理、推理和编码链路。

这意味着同一套业务逻辑可以覆盖：

- AX650N / AX8850 本地 NPU
- RK3588 / RV1126B 等 RKNN 平台
- 第三方主机外挂 AXCL 算力卡
- 多计算卡、多视频任务并发运行

### 4. 区域事件引擎

平台内置区域规则能力，支持多边形区域、绊线、方向判断、持续时间、数量阈值、冷却时间等事件逻辑。算法不只是“检测到目标”，而是能表达现场真正关心的业务规则。

典型规则：

- 区域入侵：人员进入禁区报警
- 徘徊检测：人员长时间停留报警
- 离岗检测：岗位无人超过阈值报警
- 人群聚集：区域内人数超过阈值报警
- 绊线方向：越线、逆行、进出方向统计
- 静止物体：箱子、垃圾袋、障碍物长时间停留报警

### 5. 开放词汇提示词检测

新增 `promptdet` 提示词检测插件，支持通过英文提示词定义需要关注的目标类别。用户可在 Web 端配置英文提示词，例如：

```text
person
traffic cone
trash bag
cardboard box
fire extinguisher
```

系统自动将提示词编码为文本特征，并在实时视频中检测对应目标。相比传统固定类别模型，提示词检测更适合快速变化的项目需求。

核心价值：

- 不需要为每个新增类别重新训练模型。
- 一行一个提示词，最多 5 类，提示词内部支持空格。
- 支持区域、规则、跟踪去重、连续帧确认和报警推送。
- 模型、文本编码器和词表统一打包为 `promptdet_model.axpkg`，便于工程交付。

### 6. 完整报警闭环

平台提供统一报警协议和输出链路。算法节点只需要输出结构化事件，报警插件负责本地通知、服务器推送、截图留证、录像联动和事件冷却。

支持能力：

- 本地 Web 报警弹窗
- 服务器 HTTP 报警推送
- 报警截图与录像留证
- TTS / 音频提示扩展
- 报警冷却与重复抑制
- 事件字段标准化，便于平台对接

### 7. 智能检索与事件追溯

平台不仅能在事件发生时实时报警，也能对历史报警、抓拍图片和录像片段进行结构化沉淀，支持按时间、通道、算法类型、目标类别、区域和事件状态快速检索。结合开放词汇和语义能力，可进一步扩展为“用自然语言找事件”的智能检索入口。

智能检索带来的价值：

- 从“翻录像”升级为“查事件”，快速定位关键片段。
- 支持按人、车、物、行为、区域和时间多条件过滤。
- 报警截图、录像片段、OSD 结果和结构化字段关联保存，便于复核取证。
- 可与提示词检测、LLM 二次审核结合，形成语义标签和事件摘要。
- 适合安防复盘、生产追责、运营分析和平台工单闭环。

### 8. 工程化可交付

平台从一开始面向实际项目交付设计，不依赖单机 Demo 流程。

工程能力包括：

- 模型资源随插件打包，减少部署遗漏。
- 支持 `.axpkg` 统一模型包，便于跨平台模型管理。
- 支持前端自动生成插件配置界面。
- 支持算法配置、区域配置、报警配置统一下发。
- 支持多任务、多路流、多硬件运行位置。
- 支持 SDK 二次开发和第三方算法快速集成。

## 能解决哪些现场问题

AIBox 的价值不是简单“识别到一个目标”，而是把摄像头视频转化为可处理、可追溯、可联动的业务事件。下面这些是项目中最常见、也最容易形成标准化交付的场景。

### 人员值守与岗位管理

| 现场问题                   | AIBox 解决方式                                     | 推荐能力           |
| :------------------------- | :------------------------------------------------- | :----------------- |
| 值班岗没人，无法及时发现   | 在岗位区域绘制检测区，人员离开超过设定时间自动报警 | 离岗检测           |
| 安保人员长时间未在指定位置 | 对岗亭、门岗、出入口配置无人超时规则               | 离岗检测、区域规则 |
| 夜间有人进入禁区           | 对机房、仓库、危险区绘制区域，目标进入即报警       | 区域入侵检测       |
| 人员在门口、围墙附近徘徊   | 持续停留超过阈值后报警，减少短暂经过误报           | 徘徊检测           |

### 安全生产与违规行为

| 现场问题                 | AIBox 解决方式                            | 推荐能力               |
| :----------------------- | :---------------------------------------- | :--------------------- |
| 工人未佩戴安全帽         | 检测人员头部防护状态，违规实时报警        | 安全帽检测             |
| 禁烟区域有人吸烟         | 检测吸烟行为，并可接 LLM 二次审核降低误报 | 吸烟检测、LLM 二次审核 |
| 加油站、车间有人打电话   | 检测手持手机通话动作，触发本地和平台报警  | 打电话检测             |
| 仓库、机房出现烟雾或明火 | 发现火焰、烟雾后立即推送截图和事件        | 火灾烟雾检测           |
| 人员跌倒无人发现         | 跌倒姿态触发报警，适合康养、园区、厂区    | 摔倒检测               |
| 现场发生肢体冲突         | 对异常冲突行为进行识别和推送              | 打架检测               |

### 通道、仓储与环境秩序

### 开放场景与临时需求

| 现场问题                       | AIBox 解决方式                                  | 推荐能力               |

## 提示词检测业务示例

| 业务需求           | 推荐提示词                      | 推荐规则           | 说明                             |
| :----------------- | :------------------------------ | :----------------- | :------------------------------- |
| 门口有没有包裹     | `package` / `cardboard box` | 新增物体           | 适合快递、门店、园区门口         |
| 通道有没有乱放箱子 | `box` / `carton`            | 目标静止           | 目标持续停留后报警，减少经过误报 |

| 有没有乱倒垃圾     | `trash bag` / `garbage`     | 新增物体或动作候选 | 建议结合二阶段审核或人工复核     |
| 消防器材是否缺失   | `fire extinguisher`           | 目标缺失           | 适合固定位置巡检                 |
| 是否疑似吸烟       | `cigarette` / `smoke`       | 动作候选           | 建议接吸烟专用模型或 LLM 二审    |

| 查找某个门口出现过的包裹 | 通道 +`package` / `cardboard box` 标签 | 减少人工翻录像         |
| 查找消防通道堆物记录     | 区域 +`box` / `carton` + 静止规则      | 形成整改闭环           |
| 查找某段时间所有吸烟告警 | 时间 + 吸烟检测 + 审核状态                 | 安全管理追责           |
| 查找车辆逆行或违停记录   | 车辆事件类型 + 车道区域                    | 交通秩序管理           |
| 查找误报和已确认事件     | 事件状态 + 审核结果                        | 优化算法阈值和规则配置 |

智能检索建议与报警系统联动设计：实时阶段负责“发现问题”，检索阶段负责“还原过程、定位证据、沉淀数据”。对于大型项目，可以进一步扩展为事件看板、趋势统计、问题工单和运营报表。

```text
视频输入
  └─ RTSP / 本地视频 / 摄像头

```

平台将“模型推理”升级为“事件理解”，将单点算法能力扩展为完整业务闭环。

## 为什么选择 AIBox

### 更适合边缘现场

算法在本地运行，实时性强，减少带宽占用，适合弱网、内网和隐私敏感场景。

### 更适合项目交付

插件包包含算法、配置和模型资源，部署边界清晰，减少现场安装和版本管理复杂度。

### 更适合多硬件生态

支持 AX、RK、AXCL 等多种硬件路径，同一套软件体系覆盖不同成本、算力和部署形态。

### 更适合复杂业务

区域、规则、跟踪、冷却、报警、录像全链路内置，不需要每个项目重新开发一套业务逻辑。

### 更适合事件追溯

报警、截图、录像和结构化字段统一沉淀，支持智能检索和快速复盘，让现场问题不仅能被发现，也能被查清、管住、闭环。

### 更适合快速扩展

提示词检测让项目可以快速覆盖新类别；插件 SDK 让第三方算法可以接入统一平台能力。
