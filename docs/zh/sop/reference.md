# 控件速查、术语与验收清单

[English](../../en/sop/reference.md) · [使用说明首页](index.md)

本页用于操作时快速查找。第一次使用请先按[入门示例](quickstart.md)完成一遍。

## 1. 常用控件速查

| 控件 | 做什么 | 操作后的核对 |
|---|---|---|
| 添加任务 → SOP工序 | 创建一套工序任务 | 物件模式或手部模式正确 |
| 选择 / 更换 | 选择工位摄像头 | 来源地址和实际工位一致 |
| 上传 / 录制 | 提供教学录像 | 播放及时间轴已准备好 |
| 添加目标 | 建立逻辑物件及参考 | 框内内容、名称正确 |
| 补充角度 | 给同一目标增加参考 | 没有误建为另一物件 |
| 帮我完善识别 | 抽帧并复查识别 | 范围、目标、漏检与误检 |
| 重新检测当前图片 | 使用当前试检条件检测本帧 | 算法框命中人工框的位置 |
| 采用补框 | 将标注用于方案参考 | 待采用、参考和容量变化 |
| 画区域 | 定义可复用工作区 | 形状与位置正确 |
| 本步检查关系 → 编辑 | 配置物件和动作要求 | 对象、区域、组合正确 |
| 怎样确认完成 → 设置 | 配置自动或人工完成 | 持续时间与确认时机 |
| 阶段验证范围 | 配置该阶段片段 | 端点、时长、示范同步 |
| 验证阶段 / 验证本方案 | 复核对应层级 | 原因与终态，不只看进度 |
| 检测设置 | 配置工位共享来源和方向 | 影响到哪些工序 |
| 调整顺序 | 修改阶段或组关系 | 依赖顺序与任意顺序组 |
| 撤销 | 撤销最近支持的修改 | 实际条件恢复 |
| 完成 | 返回任务草稿 | 继续确认和保存 |
| 保存 | 持久保存任务 | 成功提示和重新打开 |
| 运行 / 工位运行 | 启动已保存任务及操作页面 | 当前版本和步骤 |

## 2. 术语

| 术语 | 通俗解释 |
|---|---|
| 目标 | 要识别的某种物件，例如橡胶锤 |
| 参考图 | 告诉系统该目标长什么样 |
| 参考角度 | 同一目标的另一种正常外观 |
| 人工补框 | 人标出该帧中应识别的位置 |
| 候选 | 算法发现的可能目标，仍需核对 |
| 置信度 / 分数 | 一条识别线索的数值，不是方案准确率 |
| 阈值 / 门槛 | 接受候选所需满足的筛选要求 |
| 全局区域 | 可被多个步骤引用的工作区定义 |
| 条件 | 本步需要满足的一条要求 |
| 全部同时满足 | 同一时刻所有条件都成立 |
| 任意一项满足 | 等价条件中至少一项成立 |
| 按先后顺序 | 条件必须按配置顺序发生 |
| 任意顺序组 | 组内各工序可任意顺序完成，仍需全部完成 |
| 持续时间 | 条件应保持多久 |
| 完成时限 | 本步最多允许花多久完成 |
| 人工核对 | 视觉条件满足后，由人员检查并确认 |
| 人工确认 | 本步以人员确认作为完成依据 |
| 教学录像 | 用来建立目标和编排流程的录像 |
| 独立验证录像 | 另一次拍摄，用来复查泛化表现 |
| 草稿 | 正在编辑的配置，不等于设备已保存或运行 |

## 3. 手部动作选型

| 现场需求 | 起步方式 | 验证重点 |
|---|---|---|
| 只看工具摆好 | 物件检测 | 漏检、重复、区域、数量 |
| 看手是否可见 | 手部检测 | 遮挡、左右、多人 |
| 手靠近物件 | 手与物件靠近 | 两端可靠可见，距离合理 |
| 手靠近后离开 | 顺序动作模板 | 靠近后真实远离，非漏检 |
| 从一处移到另一处 | 支持的移送模板 | 起点、过程、终点及物理实例 |
| 无法只靠视觉判定质量 | 视觉后人工核对或人工确认 | 说明清楚、确认对象正确 |

## 4. 用户配置与页面语言

系统界面提供中文、英文、越南文、高棉文和老挝文入口。任务、方案、目标、区域及自填说明属于用户资料，切换语言不会自动翻译它们。多语言现场应使用团队都能理解的名称和说明。

中英文手册分别使用对应语言界面的截图。版本更新可能改变按钮位置；按控件用途和当前提示操作。界面仍出现与所选语言不一致的固定文字时，可向管理员反馈具体入口，不要自行改业务数据来“翻译”按钮。

## 5. 上线前检查清单

### 工位与素材

- [ ] 相机固定，方向、照明和画质符合使用条件。
- [ ] 录像能播放、定位，示范片段正确。
- [ ] 区域与真实工位一致。
- [ ] 视频和相机变化后的重验责任明确。

### 识别与规则

- [ ] 每个目标都有代表性参考。
- [ ] 正常清晰画面中的漏检、误检、重复框已处理。
- [ ] 数量、区域和手部方向已核对。
- [ ] 空间关系没有被误当成接触、抓握或加工质量证明。
- [ ] 同时、任意和先后关系符合现场依赖。
- [ ] 时长、时限与人工确认方式正确。

### 验证与运行

- [ ] 单目标、单阶段、整套方案逐级复核。
- [ ] 包含错误动作和独立录像。
- [ ] 缺帧、遮挡、断流不会被误当成完成。
- [ ] 当前结果与当前版本及范围一致。
- [ ] 完成、确认、保存后重新打开核对。
- [ ] 操作员能独立使用说明和示范完成流程。
- [ ] 记录保留、空间整理和异常处理责任明确。

可在[原始发布页](https://zenodo.org/records/4047982)取得完整录像；配套片段可从[入门示例](quickstart.md#使用配套示例录像)下载。录像与截图用于说明操作，不构成对识别准确率或生产质量的认证。
